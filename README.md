# 🕊️ Gereja Backend - Node.js + Express

Backend REST API Sistem Informasi Gereja.

## Cara Menjalankan

### 1. Install dependencies
```bash
npm install
```

### 2. Pastikan MySQL sudah jalan di XAMPP

### 3. Jalankan server
```bash
node app.js
```

Server berjalan di: **http://localhost:3000**
